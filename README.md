# Agent Flight Recorder (AFR)

A flight recorder for AI agents that move money. Every action is signed, hash-chained,
encrypted client-side, stored on Arkiv, anchored on Base and tied to an ERC-8004 identity.
A chain watcher flags on-chain actions that have no record.
