# @afr/test-vectors

Golden vectors for every hashed or signed format (L1 §11, L4). All implementations
(TS core, verifier, Python SDK, third-party verifiers) must reproduce them byte for byte.

## Immutability

- A committed vector file is **never edited or deleted**. CI fails if one changes.
- A format change needs an ADR, a new schema version, and a **new** vector file
  (e.g. `record-header.v2.json`). The old file stays to prove old evidence still verifies.
- Vectors are generated by `pnpm --filter @afr/test-vectors gen` from fixed seeds, then
  reviewed by a human before commit.

## Layout

```
vectors/<format>.v<N>.json   { "format", "version", "cases": [{ "name", "input", "expected" }] }
scripts/gen.ts               generator (P1-xx fills it in)
scripts/check.mjs            parses every vector file and checks its shape
```
